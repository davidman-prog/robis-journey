# מחברת פרויקט – המסע של רובי

## יום ראשון, 8.11.2026

1. **מה עשינו:** פתחנו את הטרמינל בתוך VS Code, העתקנו את המאגר למחשב עם `git clone`, ופתחנו אותו ב־VS Code. יצרנו את התיקייה `docs` ואת קובץ היומן. קראנו את חוברת הקורס ובנינו תוכנית לשבוע.
2. **מה למדתי:** TypeScript היא שפה, ו־VS Code הוא עורך. הטרמינל תמיד עומד בתיקייה מסוימת (מה שמופיע אחרי `PS`), ו־`git clone` מעתיק לתיקייה הזו. אחרי ה־clone יש שני עותקים, מקומי וב־GitHub, והם לא מתעדכנים לבד. למדתי גם שלושה סימנים בסיסיים של Markdown.
3. **איפה נתקעתי:** כמעט פעלתי לפי הודעה של Claude Code שהניחה שהפרויקט הוא backend עם Postgres. עצרתי ובדקתי לפני שהרצתי משהו.
4. **שימוש ב־AI:** Claude הסביר כל פקודה חלק אחרי חלק, נתן דוגמאות מתחום אחר ובדיקות נכון/לא נכון, ובנה איתי תוכנית שבועית. את כל הפקודות הקלדתי והרצתי בעצמי.
5. **מה הלאה:** יום שני (1.5 שעות): ליצור שלד Vite עם TypeScript, להבין כל קובץ, ולהריץ `npm run dev`.


## יום ראשון, 15.11.2026

1. **מה עשינו:** העליתי את היומן ל־GitHub. יצרתי שלד Vite עם TypeScript (Vanilla), הרצתי `npm install` ו־`npm run dev`, ושיניתי את הכותרת ל"המסע של רובי". הוספתי Vitest ובדיקה ראשונה, GitHub Actions שמריץ אותה בכל push, ופרסום אוטומטי ל־GitHub Pages. האתר באוויר: https://davidman-prog.github.io/robis-journey/
2. **מה למדתי:** הדרך של קובץ ב־git: `add` ← `commit` ← `push` (האותיות U, ‏A, ‏M, והמילים ahead ו־up to date). `dir`, ‏`Test-Path`, ‏`git diff`, ‏`git restore`. ‏`package.json` = רשימת קניות, `node_modules` = המצרכים (לא נשמרים ב־git), `package-lock.json` = הקבלה (`npm ci`). בדיקה צריכה לדעת להיכשל. Expected = מה שכתבתי, Received = מה שהקוד חישב. ב־YAML ההזחה קובעת. `base` ב־Vite = "מספר הדירה" של האתר.
3. **איפה נתקעתי:** העברתי את התיקייה ל־Documents, והטרמינל חיפש אותה במקום הישן. ‏Vite החליף את `.gitignore`, ושחזרתי אותו עם `git restore`. התבלבלתי בין Expected ל־Received. ב־Pages חסרים סמלים, כי בקוד הדוגמה יש כתובת שמתחילה ב־`/`.
4. **שימוש ב־AI:** ‏Claude הסביר כל פקודה ושורה, צייר שרטוטים אינטראקטיביים של git ו־npm, ובדק את ההבנה שלי בשאלות. הוא נתן את קבצי ההגדרות (`vite.config.ts`, ‏`test.yml`, ‏`deploy.yml`) עם הסבר לכל שורה. את הבדיקה הקלדתי בעצמי, ואת כל הפקודות הרצתי בעצמי.
5. **מה הלאה:** קובץ `CLAUDE.md` לעבודה עם Claude Code, בסיס TypeScript בתרגילים קטנים, מפרט השפה, ניסוי העורך, ואז מנתח המילים ו"ימינה 1" (אני כותב).
